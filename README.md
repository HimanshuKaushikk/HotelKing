# 🏨 Hotel Booking Website

🔗 Live Demo: https://hotel-king-nu.vercel.app/

---

## 📌 About Project

This is a fully responsive hotel booking website built using HTML, CSS, and JavaScript.
The project focuses on creating a modern UI and smooth user experience for hotel browsing and booking.

---

## ✨ Features

* Responsive design (mobile + desktop)
* Modern and clean UI
* Room listing section
* Booking interface (UI-based)
* Smooth navigation and layout
